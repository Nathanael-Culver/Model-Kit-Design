# Supplies Inventory

Reserved for a future consumables/accessories inventory.

Suggested fields when this is populated:

`category, brand, sku, item, size, quantity, location, status, notes`

Examples of categories: adhesives, putties/fillers, masking, thinners/reducers, cleaners, decal solutions, sanding media, tape, wire, LEDs, fiber optics, decals, pigments/mica, and PPE consumables.

The current paint inventory intentionally keeps these out of the paint CSVs so paints and supplies remain cleanly separated.
